## 🎨 Дизайн-решения:

### 1. Визуальные разделители
- Использованы символы `━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━` для разделения секций
- Четкая структура информации

### 2. Эмодзи для лучшего восприятия
- 🔍 Проверка
- 💰 Баланс
- ✅ Доступно
- ⏰ Время ожидания
- 🛡️ AI-анализ
- 📝 Инструкции
- 💬 Призыв к действию

### 3. Пошаговые инструкции
- 1️⃣ 2️⃣ 3️⃣ - нумерованные шаги
- Четкие действия для пользователя

### 4. Адаптивное содержимое
- Для пользователей с балансом > 0: показываем выбор типа проверки
- Для пользователей с балансом = 0: показываем обычную проверку
- Для пользователей с балансом >= 1 USDT: показываем доступность AI-анализа
