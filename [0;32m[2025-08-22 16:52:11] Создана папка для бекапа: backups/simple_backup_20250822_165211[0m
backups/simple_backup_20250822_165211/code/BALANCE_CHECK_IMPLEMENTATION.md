## ✅ Что реализовано:

- **Скрипт**: `add_test_balance.py`

### 2. Логика выбора типа проверки

#### Для пользователей с балансом > 0:
1. **Отправка адреса** → проверка баланса
2. **Если баланс > 0** → показываем выбор:
   - ✅ **Бесплатная проверка** — базовая информация о рисках
   - 🛡️ **Глубокий AI-анализ** — детальный отчёт с рекомендациями (1 USDT)
3. **Пользователь выбирает** → выполняется выбранный тип проверки

#### Для пользователей с балансом = 0:
1. **Отправка адреса** → обычная бесплатная проверка
2. **Применяются ограничения**: 1 проверка в минуту

#### `check_type_handler` (уже существовал):
- Обрабатывает выбор типа проверки
- Для платной проверки списывает 1 USDT
- Вызывает `perform_free_check` или `perform_paid_check`

### 4. Функции проверки

#### `perform_free_check`:
- Базовая проверка через MetaSleuth API
- Сохраняет результат как `CheckType.FREE`
- Обновляет `last_free_check`

#### `perform_paid_check`:
- Глубокий анализ с GPT
- Списывает 1 USDT с баланса
- Сохраняет результат как `CheckType.PAID`
- Показывает детальный отчет
