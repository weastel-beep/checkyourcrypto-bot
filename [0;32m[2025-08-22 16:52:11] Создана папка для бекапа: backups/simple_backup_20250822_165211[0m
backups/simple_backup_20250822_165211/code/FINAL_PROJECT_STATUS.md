### Heroku конфигурация:
```bash
App: checkyourcrypto-bot
URL: https://checkyourcrypto-bot-87c446f24699.herokuapp.com/
Dynos: web (Django) + worker (Telegram Bot) + alerts
Database: Heroku PostgreSQL
```

### Процессы:
```bash
web: cd admin_app && gunicorn wsgi:application --bind 0.0.0.0:$PORT --workers 2 --timeout 120
worker: python bot/main_simple.py
alerts: python -m alerts_bot.main
```
