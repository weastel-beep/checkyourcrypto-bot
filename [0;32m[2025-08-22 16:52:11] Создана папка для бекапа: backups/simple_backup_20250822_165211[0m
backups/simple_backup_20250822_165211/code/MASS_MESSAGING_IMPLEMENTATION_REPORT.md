## 🏗️ Архитектура системы

### Модели данных

#### MassMessage
```python
class MassMessage(Base):
    id: int
    title: str
    content: str
    language: str
    status: MassMessageStatus
    min_balance: Optional[Decimal]
    max_balance: Optional[Decimal]
    user_language: Optional[str]
    is_active_only: bool
    scheduled_at: Optional[datetime]
    sent_at: Optional[datetime]
    total_users: int
    sent_count: int
    failed_count: int
```

#### MassMessageRecipient
```python
class MassMessageRecipient(Base):
    id: int
    mass_message_id: int
    user_id: int
    status: OutboxStatus
    sent_at: Optional[datetime]
    error_message: Optional[str]
    retry_count: int
```

### Сервис MassMessagingService

Основные методы:
- `create_mass_message()` - Создание сообщения
- `get_users_for_mass_message()` - Получение получателей с фильтрами
- `prepare_mass_message()` - Подготовка к отправке
- `send_mass_message()` - Отправка сообщений
- `schedule_mass_message()` - Планирование отправки
- `cancel_mass_message()` - Отмена сообщения
- `get_mass_message_stats()` - Статистика
- `process_scheduled_messages()` - Обработка запланированных

## 🛠️ Инструменты управления

### CLI-интерфейс

```bash
# Создание сообщения
python scripts/mass_messaging_cli.py create \
    --title "Важное уведомление" \
    --content "У нас обновление!" \
    --language ru

# Список сообщений
python scripts/mass_messaging_cli.py list

# Статистика
python scripts/mass_messaging_cli.py stats 1

# Отправка
python scripts/mass_messaging_cli.py send 1

# Планирование
python scripts/mass_messaging_cli.py schedule 1 --datetime "2025-08-21T15:00:00"
```

### Воркер для запланированных сообщений

```bash
# Запуск воркера
python scripts/mass_messaging_worker.py
```

Воркер автоматически проверяет запланированные сообщения каждую минуту и отправляет их в назначенное время.

## 🎛️ Фильтры пользователей

### Доступные фильтры

1. **По балансу**
   - `min_balance` - минимальный баланс
   - `max_balance` - максимальный баланс

2. **По активности**
   - `is_active_only=True` - только активные за 30 дней

3. **По языку**
   - `user_language` - фильтр по языку пользователя

4. **Автоматические**
   - Исключение заблокированных пользователей
   - Учет последней активности

## 📊 Статусы сообщений

### MassMessage
- `draft` - черновик
- `scheduled` - запланировано
- `sending` - отправляется
- `completed` - завершено
- `cancelled` - отменено
- `failed` - ошибка

### MassMessageRecipient
- `pending` - ожидает отправки
- `sent` - отправлено
- `failed` - ошибка отправки

## 🔒 Безопасность

### Права доступа
- CLI доступен только администраторам
- Команда `/broadcast` в алертах боте ограничена ops_chat_id
- Все операции логируются

### Ограничения
- Максимальный размер сообщения: 4096 символов
- Задержка между отправками: 0.1 секунды
- Размер батча: 50 сообщений
