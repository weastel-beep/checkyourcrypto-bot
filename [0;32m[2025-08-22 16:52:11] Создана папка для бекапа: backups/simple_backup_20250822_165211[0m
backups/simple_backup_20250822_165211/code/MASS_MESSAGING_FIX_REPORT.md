## 🔍 Обнаруженные проблемы

### 1. Несоответствие в модели SQLAlchemy
**Проблема**: Модель `MassMessage` в `common/models.py` использовала неправильное название колонки
- В модели: `name="is_active"` 
- В базе данных: `is_active_only`

**Решение**: Исправлено в строке 181:
```python
is_active_only: Mapped[bool] = mapped_column(Boolean, default=True, name="is_active_only")
```

### 2. Лишнее поле created_by_id
**Проблема**: Модель пыталась использовать поле `created_by_id`, которого нет в базе данных
**Решение**: Закомментировано поле в SQLAlchemy модели

### 3. Несоответствие Django модели
**Проблема**: Django модель в `admin_app/core/admin_models.py` не соответствовала структуре базы данных
**Решение**: 
- Исправлено поле `is_active` → `is_active_only` с правильным `db_column`
- Закомментировано поле `created_by`
- Исправлены импорты в админ-панели

### 4. Отсутствие тестовых данных
**Проблема**: В базе данных не было пользователей для тестирования
**Решение**: Создан скрипт для добавления тестовых пользователей
