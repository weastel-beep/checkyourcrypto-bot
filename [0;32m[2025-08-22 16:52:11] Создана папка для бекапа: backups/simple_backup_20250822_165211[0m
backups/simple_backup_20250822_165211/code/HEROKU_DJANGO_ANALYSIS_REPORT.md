### 2. Ключевые проблемы и решения

#### Проблема 1: Конфликт баз данных
**Проблема:** Django использует PostgreSQL, SQLAlchemy пытается использовать SQLite
**Решение:** Создана умная конфигурация в `common/config.py`
```python
@property
def sqlalchemy_database_url(self) -> str:
    django_db_url = os.getenv('DATABASE_URL')
    if django_db_url.startswith('postgresql://'):
        return django_db_url.replace('postgresql://', 'postgresql+asyncpg://', 1)
    return django_db_url
```

#### Проблема 2: Переменные окружения
**Проблема:** Django не может найти `BOT_TOKEN`
**Решение:** Правильная загрузка переменных в `settings.py`
```python
from dotenv import load_dotenv
load_dotenv()
BOT_TOKEN = os.getenv('BOT_TOKEN', 'default-token')
```

#### Проблема 3: Схема базы данных
**Проблема:** Несоответствие имен колонок
**Решение:** Синхронизация моделей Django и SQLAlchemy
```python
# Django
is_active_only = models.BooleanField(default=True, db_column='is_active')

# SQLAlchemy
is_active_only: Mapped[bool] = mapped_column(Boolean, default=True, name="is_active")
```

## 🚨 Типичные проблемы и решения

### 1. "No module named 'aiosqlite'"
**Причина:** SQLAlchemy пытается использовать SQLite на Heroku
**Решение:** Автоматическое определение типа БД и использование правильного драйвера

### 2. "'Settings' object has no attribute 'BOT_TOKEN'"
**Причина:** Django не может найти переменную окружения
**Решение:** Правильная загрузка переменных через `load_dotenv()`

### 3. "column does not exist"
**Причина:** Несоответствие схемы БД
**Решение:** Синхронизация моделей и применение миграций

### 4. "WSGI application could not be loaded"
**Причина:** Неправильный путь к WSGI приложению
**Решение:** Корректная конфигурация Procfile и wsgi.py
