# Документация флоу проверки адресов

## Текущий флоу

### 1. Пользователь с балансом = 0
1. Отправляет адрес
2. Получает бесплатную проверку
3. В результате видит кнопки:
   - 🛡️ Глубокий AI-анализ (1 USDT)
   - 📊 Посмотреть пример

### 2. Пользователь с балансом > 0
1. Отправляет адрес
2. Получает выбор типа проверки:
   - ✅ Бесплатная проверка
   - 🛡️ Глубокий AI-анализ (1 USDT)
3. Если выбирает бесплатную:
   - Получает бесплатную проверку
   - В результате видит кнопки:
     - 🛡️ Глубокий AI-анализ (1 USDT)
     - 📊 Посмотреть пример

## Важные моменты для будущих изменений

### Кнопка "Посмотреть пример"
- **Всегда** должна быть в результатах бесплатной проверки
- Показывает пример того, что дает платный анализ
- Мотивирует пользователя попробовать платную проверку

## Callback данные
- `free_check` - бесплатная проверка
- `paid_check` - платная проверка  
- `show_example` - показать пример
- `back_to_check` - вернуться к результату проверки
- `new_check` - новая проверка
- `add_balance` - пополнить баланс

## Логика лимитов
- 1 бесплатная проверка в минуту
- Платные проверки без лимитов (если есть баланс)
