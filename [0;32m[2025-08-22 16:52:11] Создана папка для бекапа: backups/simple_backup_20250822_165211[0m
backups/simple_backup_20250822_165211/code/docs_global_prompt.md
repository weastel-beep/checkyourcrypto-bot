# GLOBAL_PROMPT — Check Your Crypto (версия v1.5)

**Краткое TL;DR (самое важное):**

1. Деплой: **Heroku** (web — Django admin, worker — основной Telegram-бот long-polling, alerts — отдельный бот/worker).
2. Бесплатные проверки: используем **MetaSleuth (купленные ключи)** — Wallet Screening + Address Label.
3. **Система ограничений**: УПРОЩЕННАЯ модель - 1 бесплатная проверка в минуту для всех пользователей.
4. **Монетизация**: Binance Pay (заглушка), тестовые платежи, глубокий AI-анализ за 1 USDT.
5. Статические/медиа файлы (логотипы payment methods и др.): **AWS S3**.
6. База данных: **Postgres** (Heroku Postgres). ORM: SQLAlchemy 2.x (async) + Alembic миграции.
7. Админка: **Django** (web dyno).
8. Мониторинг: Sentry + worker heartbeat + `/health` endpoint + alerts bot.
9. Промт и спецификации хранятся в `docs_global_prompt.md` (эта версия v1.5). При дальнейшем обращении указывать версию.

## Обязательные предпосылки (core assumptions)

- Использовать **Heroku** как целевую платформу для MVP.
- MetaSleuth — главный источник данных для бесплатных проверок (используется оплаченный ключ). Ссылки на API: Wallet Screening API и Address Label API.
- Платежи — на этапе MVP **stub** (фейковые инвойсы); реальная интеграция состоится позже.
- Логотипы и загружаемые файлы хранятся в **S3** (AWS).
- Два Telegram-бота: пользовательский (`@CheckYourCrypto_bot`) и отдельный alerts/ops-бот.
- Язык разработки: русский (вся документация и комментирование в репо — на русском).

## Переменные окружения (обязательные)

- `BOT_TOKEN` — токен основного бота
- `ALERT_BOT_TOKEN` — токен alerts бота
- `OPS_CHAT_ID` — chat_id для оповещений
- `METASLEUTH_WALLET_SCREENING_KEY` — ключ MetaSleuth для Wallet Screening
- `METASLEUTH_ADDRESS_LABEL_KEY` — ключ MetaSleuth для Address Label
- `DATABASE_URL` — Postgres (формат для async: postgresql+asyncpg://...)
- `ADMIN_SECRET` — секрет для входа в админку
- `MOCK_METASLEUTH` — true/false (для локального теста)
- `AWS_S3_BUCKET`, `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_REGION`
- `OPTIONAL_SLACK_WEBHOOK_URL` — опционально для уведомлений

### 🔧 **Настройки системы ограничений (УПРОЩЕННЫЕ):**

- `MIN_INTERVAL_SECONDS` — минимальный интервал между проверками (по умолчанию: 60 секунд = 1 минута)

## Система ограничений (УПРОЩЕННАЯ ВЕРСИЯ)

### Текущая логика:
1. **Все пользователи**: 1 бесплатная проверка в минуту
2. **Нет сложных тарифов**: убраны статусы new_user, basic, standard, premium, VIP
3. **Простое ограничение**: `MIN_INTERVAL_SECONDS = 60` (1 минута)

### Файлы:
- `common/check_limits.py` - основная логика ограничений
- `common/services.py` - UserService.can_use_free_check()

### Пример использования:
```python
from common.check_limits import check_limits
can_free, wait_time = check_limits.can_perform_free_check(user)
```

```bash

heroku ps --app checkyourcrypto-bot

# Запустить/остановить worker (бот)
heroku ps:scale worker=1 --app checkyourcrypto-bot
heroku ps:scale worker=0 --app checkyourcrypto-bot
```
