**Фронтенд:**
```bash

npm install winston
```

**Бэкенд:**
```bash
cd admin_panel_new
pip install psutil
```

### 2. Настройка переменных окружения

Добавить в `.env`:
```env
# Логирование
LOG_LEVEL=INFO
LOG_FORMAT=json
ENVIRONMENT=production

# Мониторинг
ENABLE_PERFORMANCE_LOGGING=true
ENABLE_DATABASE_LOGGING=true
```

### 3. Настройка внешних сервисов логирования

**Для продакшена рекомендуется:**

1. **Sentry** - для отслеживания ошибок
2. **LogRocket** - для сессионного воспроизведения
3. **DataDog** - для мониторинга производительности
4. **ELK Stack** - для централизованного логирования

### 4. Обновление остальных компонентов

Заменить `console.log` в остальных Vue компонентах:

```javascript

```

## 📊 Метрики для мониторинга

### Ключевые показатели:

1. **Время ответа API**
   - Цель: < 500ms для 95% запросов
   - Алерт: > 2s

2. **Количество ошибок**
   - Цель: < 1% от всех запросов
   - Алерт: > 5%

3. **Доступность сервиса**
   - Цель: > 99.9%
   - Алерт: < 99%

4. **Использование ресурсов**
   - CPU: < 80%
   - Память: < 80%
   - Диск: < 90%

## 🚨 Алерты и уведомления

### Настройка алертов:

1. **Критические ошибки** (500, 502, 503)
   - Мгновенное уведомление в Slack
   - SMS/Telegram для администраторов

2. **Высокая нагрузка**
   - CPU > 80% более 5 минут
   - Память > 80% более 5 минут

3. **Проблемы с базой данных**
   - Время ответа > 1 секунды
   - Ошибки подключения

4. **Проблемы с API**
   - Количество ошибок > 5% за 5 минут
   - Время ответа > 2 секунды

## 🔧 Автоматизация

### Скрипты для мониторинга:

```bash
#!/bin/bash
# check_health.sh

# Проверка здоровья API
response=$(curl -s -o /dev/null -w "%{http_code}" https://api.example.com/health)

if [ $response -ne 200 ]; then
    echo "API health check failed: $response"
    # Отправка алерта
    curl -X POST -H 'Content-type: application/json' \
        --data '{"text":"API health check failed: '$response'"}' \
        https://hooks.slack.com/services/YOUR_WEBHOOK
fi
```

### Cron задачи:

```bash
# Проверка каждые 5 минут
*/5 * * * * /path/to/check_health.sh

# Очистка старых логов каждый день
0 2 * * * find /path/to/logs -name "*.log" -mtime +30 -delete
```
