## 🔧 Rollback план

### Если Admin API не работает
1. Откатить Admin API на предыдущую версию
2. Обновить `ADMIN_API_URL` в боте на старый URL
3. Перезапустить бота

### Если Bot не работает
1. Откатить Bot на предыдущую версию
2. Проверить webhook настройки
3. Перезапустить бота

### Если база данных недоступна
1. Восстановить из backup
2. Проверить подключения
3. Перезапустить приложения
