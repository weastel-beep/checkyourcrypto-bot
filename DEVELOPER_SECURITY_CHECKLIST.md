# 🔒 CHECKLIST БЕЗОПАСНОСТИ ДЛЯ РАЗРАБОТЧИКОВ

## Перед каждым коммитом:

### ✅ Проверка файлов
- [ ] Нет .env файлов в коммите
- [ ] Нет файлов с секретами (config.txt, credentials.json, etc.)
- [ ] Нет хардкод токенов в коде
- [ ] Все секреты используют переменные окружения

### ✅ Проверка кода
- [ ] Запущен pre-commit хук: `pre-commit run --all-files`
- [ ] Нет секретов в логах или print statements
- [ ] Нет секретов в комментариях
- [ ] Проверен detect-secrets: `detect-secrets audit .secrets.baseline`

## При настройке окружения:

### ✅ Локальная разработка
- [ ] Скопирован .env.example в .env
- [ ] Заполнены все необходимые переменные
- [ ] .env добавлен в .gitignore
- [ ] Установлены pre-commit хуки

### ✅ Production деплой
- [ ] Все секреты установлены в переменных окружения
- [ ] Нет секретов в коде или конфигурации
- [ ] Проверены права доступа к секретам
- [ ] Включено логирование безопасности

## Регулярные проверки:

### ✅ Еженедельно
- [ ] Обновлены зависимости: `pip install -r requirements.txt --upgrade`
- [ ] Проверены уязвимости: `safety check`
- [ ] Сканирование кода: `bandit -r .`
- [ ] Обновлен baseline секретов: `detect-secrets scan --baseline .secrets.baseline .`

### ✅ Ежемесячно
- [ ] Аудит безопасности кода
- [ ] Проверка прав доступа
- [ ] Обновление токенов (если необходимо)
- [ ] Проверка логов на подозрительную активность

## В случае утечки секретов:

### 🚨 Немедленные действия
1. **ОТОЗВАТЬ** скомпрометированные токены
2. **СОЗДАТЬ** новые токены
3. **ОБНОВИТЬ** все сервисы
4. **УВЕДОМИТЬ** команду
5. **ДОКУМЕНТИРОВАТЬ** инцидент

### 🔍 Расследование
- [ ] Определить источник утечки
- [ ] Проверить все коммиты на наличие секретов
- [ ] Очистить историю Git если необходимо
- [ ] Обновить процедуры безопасности

## Полезные команды:

```bash
# Проверка на секреты
detect-secrets scan --baseline .secrets.baseline .
detect-secrets audit .secrets.baseline

# Сканирование уязвимостей
bandit -r .
safety check

# Pre-commit проверки
pre-commit run --all-files

# Поиск секретов в истории
git log --all --full-history --grep="password\|secret\|token\|key"

# Проверка .env файлов
find . -name "*.env" -not -path "./.git/*"
```
